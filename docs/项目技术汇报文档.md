## 1. 项目概述

### 1.1 项目背景

海上风力发电设备长期服役于**高温、高湿、高盐雾**三重叠加的海洋大气腐蚀环境。以南海某海上风电项目为例，全年连续监测数据表明：

| 环境参数 | 实测值 | 腐蚀影响 |
|:---|:---|:---|
| 年平均气温 | **23.3°C** | 加速电化学反应速率 |
| 年平均相对湿度 | **84%** | 远超 76% NaCl 潮解临界湿度 |
| 氯离子沉积率 | 60~300 mg/(m²·day) | 破坏金属钝化膜，引发点蚀 |

机舱、控制柜等电气设备若内部湿度无法控制在 60% 以下，电气元件凝露腐蚀将不可避免。传统离线巡检模式存在四大致命缺陷：

| 缺陷 | 表现 | 工程后果 |
|:---|:---|:---|
| **时效性不足** | 年度巡检，无法捕捉腐蚀动态变化 | 发现时可能已严重减薄 |
| **分辨率不足** | 超声波测厚精度 0.1mm 级 | 无法检测 μm 级早期腐蚀 |
| **温度干扰严重** | 电阻探针 10°C 温差可产生约 3.9% 电阻伪信号 | 虚假腐蚀报警或漏报 |
| **点蚀无法识别** | 均匀腐蚀假设严重低估局部穿孔风险 | 突发性结构失效 |

**经济损失量化**：单台风机全生命周期（25 年）中，一次重大腐蚀事故的维修成本（含停机损失）约为 **600~1200 万元**，而部署在线监测的总成本约为 **30~60 万元**，仅相当于一次事故维修成本的 **5%~10%**。

### 1.2 项目目标

本系统旨在构建一套**在线、实时、高精度、误差自免疫**的腐蚀度检测系统，实现以下核心目标：

1. **多物理量协同监测**：同时采集温度、湿度、氯离子沉积率、均匀腐蚀深度（双模式）、点蚀因子共 7 个维度的环境与腐蚀参数
2. **四级误差补偿管道**：从硬件差分到自适应卡尔曼滤波，逐级消除温度漂移、恒流源漂移、湿度伪信号等误差源
3. **双模冗余交叉验证**：电阻探针（ER）+ 电感探针（LDC1614）双技术路线互为校验，精准识别温度冲击与点蚀
4. **ISO 国际标准合规**：严格遵循 ISO 9223/9224 大气腐蚀性分类与长期预测标准
5. **工业级可靠性**：支持断网补传、看门狗自恢复、多级告警与 RBAC 权限控制

## 2. 硬件组件检测原理

### 2.1 总体硬件方案

系统在 MCU 端部署 **5 种传感器**，通过 UART/RS-485 串行总线（115200 bps）将采集数据上传至边缘计算工控机。MCU 采用 **MSP430FR 系列**超低功耗微控制器，工作模式为：

```
休眠 (< 2µA) → RTC 定时唤醒 → 传感器顺序采集 (< 100ms) → 数据组包发送 (< 50ms) → 再次休眠
```

平均功耗 < 50 µW，配合 19Ah 锂亚硫酰氯电池，设计续航 > 5 年。

### 2.2 Pt1000 铂电阻温度传感器

#### 2.2.1 物理原理

铂电阻温度计基于金属导体的**电阻-温度正相关性**。当环境温度升高时，铂原子晶格热振动加剧，自由电子在电场驱动下与晶格碰撞（散射）概率增大，导致电阻率 ρ 上升，宏观表现为电阻值 R 增大。

#### 2.2.2 检测机制——Callendar-Van Dusen (CVD) 方程

Pt1000 在 IEC 60751 标准下采用 Callendar-Van Dusen 方程描述其电阻-温度特性：

**正温度区 (T ≥ 0°C)**：

```
R(T)（电阻-温度函数） = R₀（零度标称电阻） × (1 + α（一次温度系数）·T（温度） + β（二次温度系数）·T²)
```

**负温度区 (T < 0°C)**：

```
R(T)（电阻-温度函数） = R₀（零度标称电阻） × (1 + α（一次温度系数）·T（温度） + β（二次温度系数）·T² + δ（低温修正系数）·(T − 100)·T³)
```

**系数定义**：

| 符号 | 名称 | 数值 | 单位 |
|:---|:---|:---|:---|
| R₀ | 0°C 标称电阻 | **1000** | Ω |
| α | 线性温度系数 | **3.9083 × 10⁻³** | /°C |
| β | 二次温度系数 | **−5.775 × 10⁻⁷** | /°C² |
| δ | 低温修正项系数 | **−1.508 × 10⁻⁷** | — |

#### 2.2.3 逆解算法——从电阻值求温度

已知 R(T) 反推温度 T 时，正温区（T ≥ 0°C）使用**二次方程求根公式**直接解析求解：

```
二次方程: β（二次温度系数）·T² + α（一次温度系数）·T + (1 − R（电阻）/R₀（零度电阻）) = 0

T（温度） = [−α（一次温度系数） + √(α² − 4β（二次温度系数）(1 − R（电阻）/R₀（零度电阻）))] / (2β)
```

负温区（T < 0°C）由于引入四次项 δ·(T−100)·T³，需使用 **Newton-Raphson 数值迭代法**求解，最大迭代 50 次，收敛容差 1×10⁻¹⁰。

#### 2.2.4 技术参数

| 参数 | 规格 |
|:---|:---|
| 精度等级 | **Class A** (IEC 60751) |
| 温度精度 | **±(0.15 + 0.002×\|T\|) °C** |
| 长期漂移 | < 0.04%/年 |
| 温度测量范围 | −50°C ~ +300°C |
| 自热效应 | < 0.1°C @ 1mA 激励电流 |

### 2.3 SHT35 数字温湿度传感器

#### 2.3.1 物理原理

SHT35 的湿度检测基于**电容式高分子感湿膜原理**：

1. 感湿膜（聚酰亚胺类高分子材料）暴露于环境空气中
2. 水分子被吸附/解吸于薄膜内，改变其**介电常数 εᵣ**
3. 水的 εᵣ ≈ **80**，远大于干燥高分子膜的 εᵣ ≈ **3~4**
4. εᵣ 变化 → 电容 C 变化 → 内部振荡器频率变化 → 经 ADC 和校准补偿 → 数字输出 RH

#### 2.3.2 数字转换公式

```
T[°C]（摄氏温度）  = −45 + 175 × (S_T（原始温度码） / (2¹⁶ − 1))
RH[%]（相对湿度）   = 100 × (S_RH（原始湿度码） / (2¹⁶ − 1))
```

其中 S_T 和 S_RH 为 16-bit 原始 ADC 读数。

#### 2.3.3 CRC-8 数据完整性校验

SHT35 在每个传感器读数后附加 **CRC-8 校验字节**，确保 I²C 通信数据的完整性：

| CRC 参数 | 值 |
|:---|:---|
| 多项式 | **0x31** (x⁸ + x⁵ + x⁴ + 1) |
| 初始值 | 0xFF |
| 校验范围 | 温度 2 字节 + 湿度 2 字节 |
| 校验结果 | 分别生成温度 CRC 和湿度 CRC |

**6 字节 I²C 数据包结构**：

```
Byte 0-1: T_raw (MSB first, 16-bit)
Byte 2:   T CRC-8
Byte 3-4: RH_raw (MSB first, 16-bit)
Byte 5:   RH CRC-8
```

#### 2.3.4 技术参数

| 参数 | 规格 |
|:---|:---|
| 湿度精度 | **±1.5% RH** (20%~80%RH 范围) |
| 温度精度 | ±0.1°C (典型) |
| I²C 地址 | 0x44 (7-bit) |
| 典型功耗 | 2 µA @ 1 Hz 采样率 |
| 特殊功能 | 76% RH NaCl 潮解临界值检测 |
| 响应时间 | 8 秒 (τ63%, 湿度) |

#### 2.3.5 76% 湿度临界值的腐蚀学意义

NaCl（海盐的主要成分）在相对湿度达到 **76% RH** 时发生**潮解**——固体盐颗粒吸收空气中水分形成饱和盐溶液膜。此液膜为金属表面提供了电解质环境，电化学腐蚀反应得以发生。因此 **76% RH 被定义为腐蚀临界湿度**，是数据有效性的重要判定依据。

### 2.4 QCM 石英晶体微天平（盐度传感器）

#### 2.4.1 物理原理

QCM 基于石英晶体的**压电效应**和**质量敏感特性**。石英晶体在交流电场激励下产生厚度剪切振动，其谐振频率为：

```
f₀（基频） = v（声速） / (2·t_q（晶片厚度）)
```

其中 v 为声波在石英中的传播速度，t_q 为晶片厚度。

当晶体表面沉积外来物质时，等效厚度增加，谐振频率下降。这种频率-质量转换关系由 **Sauerbrey 方程**描述。

#### 2.4.2 核心算法——Sauerbrey 方程

```
         −2·f₀²
Δf（频率偏移） = ───────────── × Δm（质量变化）
      A（电极面积）·√(ρ_q（石英密度）·μ_q（剪切模量）)

即：Δf（频率偏移） ≈ −2.26×10⁸ × Δm（质量变化）/A（电极面积）   （代入 10MHz 晶振参数）
```

**物理常数**：

| 符号 | 名称 | 数值 |
|:---|:---|:---|
| f₀ | 晶振基频 | **10.0 MHz** |
| ρ_q | 石英密度 | 2648 kg/m³ |
| μ_q | 石英剪切模量 | 2.947 × 10¹⁰ Pa |
| A | 电极面积 | 1.0 × 10⁻⁴ m² (1 cm²) |
| 简化灵敏度因子 | 2f₀²/√(ρ_q·μ_q) | **2.26 × 10⁸** Hz·m²/kg |

#### 2.4.3 氯离子沉积率计算

盐雾中的氯盐颗粒沉积于 QCM 电极表面后：

```
1. Δf（频率偏移）读数 → Δm（质量变化） = −Δf（频率偏移） / (2.26×10⁸) × A（电极面积）  （求得质量变化）
2. Cl_deposition（氯离子沉积率） = (Δm（质量变化） / (A（电极面积）·Δt（时间间隔）)) × 8.64×10¹⁰  （转换为 mg/(m²·day)）
```

其中 8.64×10¹⁰ 为 kg/(m²·s) → mg/(m²·day) 单位转换因子。

#### 2.4.4 灵敏度分析

| 参数 | 指标 |
|:---|:---|
| 频率分辨率 | 0.1 Hz |
| 最小可检测质量 | **~1 ng** (1 cm² 电极) |
| 沉积率检测下限 | ~1 mg/(m²·day) |
| 盐爆事件检测 | 2% 概率随机盐雾冲击模拟 |

### 2.5 电阻探针 (ER Probe)——叠加式双环差分结构

#### 2.5.1 设计原理——消除 ρ(T) 的物理方案

金属电阻的温度依赖性（ρ(T) 随 T 变化）是电阻法测腐蚀厚度的核心误差源。**叠加式双环差分结构**通过巧妙的物理设计从根本上解决这一问题：

**结构设计**：

```
        传感环 R_s(T) ─── 暴露于腐蚀环境，厚度 d 持续减薄
恒流源 I ──┤
        参考环 R_r(T) ─── Parylene C 涂层隔离（厚度 d₀ 不变）
```

两个环由**同一材料**（碳钢 C1018）、**同一恒流源** I 串联驱动，处于**同一温度场** T 中。

**差分消去推导**：

```
传感环: R_s(T)（传感环电阻） = ρ(T)（电阻率） × L（长度） / [w（线宽） × (d₀（初始厚度） − Δd（腐蚀深度）)]
参考环: R_r(T)（参考环电阻） = ρ(T)（电阻率） × L（长度） / [w（线宽） × d₀（初始厚度）]

两式相除：
R_s（传感环电阻）/R_r（参考环电阻） = [ρ(T)（电阻率）·L（长度）/(w（线宽）(d₀（初始厚度）−Δd（腐蚀深度）))] / [ρ(T)（电阻率）·L（长度）/(w（线宽）·d₀（初始厚度）)]
        = d₀（初始厚度） / (d₀（初始厚度） − Δd（腐蚀深度）)

ρ(T)（电阻率）、L（长度）、w（线宽） 全部消去！
```

**工作公式**：

```
Δd（腐蚀深度） = d₀（初始厚度） × (1 − R_r（参考环电阻）/R_s（传感环电阻）)
```

**关键参数**：

| 参数 | 符号 | 默认值 |
|:---|:---|:---|
| 初始厚度 | d₀ | **100 μm** |
| 有效比值范围 | R_s/R_r | 0.5 ~ 2.0 (夹持保护) |
| 恒流源稳定容差 | — | < 0.1% |
| 滑动窗口 | — | 10 个读数 |

#### 2.5.2 比值法自校准——消除恒流源 I 漂移

恒流源 I 长期运行可能漂移，但比值法可以进一步消除此影响：

```
V_mid（中点电压）  = I（恒流） × R_r（参考环电阻）                    → 用作参考电压 V_ref
V_diff（差分电压） = I（恒流） × (R_s（传感环电阻） − R_r（参考环电阻）)            → 用作差分电压

V_diff（差分电压） / V_mid（中点电压） = (R_s（传感环电阻） − R_r（参考环电阻）) / R_r（参考环电阻）  = R_s/R_r − 1

I（恒流） 被消去！
```

**最终工作公式（电压直接输入）**：

```
Δd（腐蚀深度） = d₀（初始厚度） × [1 − 1/(1 + V_diff（差分电压）/V_mid（中点电压）)]
```

#### 2.5.3 湿度门控有效性验证

在干燥条件下（RH < 76%），NaCl 颗粒未潮解，无法形成腐蚀电解质液膜，此时 ER 探针检测到的厚度变化可能为**干燥盐颗粒物理沉积**而非真实腐蚀。系统通过湿度门控进行过滤：

```
若 RH（相对湿度） < 76% 且 |Δd_raw（原始腐蚀深度）| ≥ ε_noise（噪声阈值） → ValidFlag（有效标志） = 0（标记为无效可疑信号）
若 RH（相对湿度） < 76% 且 |Δd_raw（原始腐蚀深度）| < ε_noise（噪声阈值） → ValidFlag（有效标志） = 1（信号在噪声水平内，通过）
若 RH（相对湿度） ≥ 76%                       → ValidFlag（有效标志） = 1（满足腐蚀条件，始终通过）
```

其中 ε_noise（噪声阈值） 由 24 小时初始数据的 3σ（3倍标准差） 统计确定。

### 2.6 电感探针 (LDC1614)——涡流法非接触测厚

#### 2.6.1 物理原理

涡流检测基于**法拉第电磁感应定律**。当高频交流电流流过平面线圈时，产生交变磁场。若导电金属试片置于线圈下方，交变磁场会在试片内感应出**涡流**（eddy current），而涡流又产生反向磁场抵消原激励磁场。

**物理量改变链**：

```
试片腐蚀减薄 d ↓
→ 涡流截面积 A_eddy ↓
→ 涡流路径等效电阻 R₂ ↑
→ 涡流产生的反射去磁效应减弱
→ 线圈等效电感 L_eq ↑
```

即：**d ↓ → L_eq ↑**，电感变化量与试片厚度变化量存在可标定的单调映射关系。

#### 2.6.2 LDC1614 芯片特性

TI LDC1614 是一款 4 通道、28-bit 高精度电感数字转换器：

| 参数 | 规格 |
|:---|:---|
| 分辨率 | **28 bits** |
| 参考时钟 f_ref | 40.0 MHz |
| I²C 地址 | 0x2A |
| 通道数 | 0~3 (单芯片支持 4 路线圈) |
| 谐振电容 | 100 pF (典型) |
| 转换公式 | f_sensor（传感器频率） = f_ref（参考时钟） × (DATAx（原始数据码） / 2²⁸) |

**电感值解算**：

```
f_sensor（传感器频率） = f_ref（参考时钟） × (DATAx（原始数据码） / 2²⁸)
L_eq（等效电感） = 1 / (C（谐振电容）·(2π·f_sensor（传感器频率）)²)
```

**腐蚀深度换算**：

```
Δd（腐蚀深度） = calibration_factor（标定因子） × (L_eq_current（当前电感） − L_eq_initial（初始电感）)
```

#### 2.6.3 为什么电感探针是"黄金判据"

电感涡流法**本征地几乎不受温度波动影响**——因为：
- 涡流信号的载体是**磁场耦合**，而非电阻的直接测量
- 金属电导率 σ 虽随温度变化，但涡流响应对 σ 的变化灵敏度远低于电阻法的 1:1 直接映射关系
- 因此在温度剧烈变化（如昼夜温差 > 10°C）的场景下，电感探针的读数稳定性显著优于电阻探针

这使得电感探针成为验证 ER 探针信号真伪的**独立参考标准**，在双模交叉验证中承担"仲裁者"角色。

### 3.5 POST 开机自检

系统启动时执行 5 步开机自检（Power-On Self Test），按顺序依次执行，任一项失败根据严重度决定是否阻止启动：

```
步骤 1: RAM 自检 ──→ 写入 0xAA/0x55 棋盘模式 4096 字节 → 回读验证
                     失败 → 系统级错误，阻止启动

步骤 2: 存储检测 ──→ 数据库文件可读写 + 磁盘剩余空间 > 100 MB
                     不足 100 MB → WARNING，允许启动但限制写入

步骤 3: 总线扫描 ──→ I²C / SPI 通信链路检测
                     失败 → WARNING，标记对应传感器不可用

步骤 4: RTC 验证  ──→ 系统时钟 ≥ 2020-01-01（排除未初始化默认值 1970/2000）
                     失败 → ERROR，阻止启动

步骤 5: 恒流源    ──→ V_ref 在标称 2.5V ±5% (2.375~2.625V) 范围内
                     失败 → ERROR，阻止启动
```

### 4.2 Level 1: 硬件差分补偿

**目的**：从电阻读数计算原始腐蚀深度，同时消除金属电阻率 ρ(T) 的温度依赖性。

**输入**：V_mid（参考环电压）、V_diff（差分电压）、d₀（初始厚度）

**算法步骤**：

```
Step 1: R_s（传感环电阻）/R_r（参考环电阻） = 1 + V_diff（差分电压） / V_mid（中点电压）
        验证 0.5 < R_s/R_r < 2.0（夹持保护，防止电路故障导致的荒谬值）

Step 2: Δd_raw（原始腐蚀深度） = d₀（初始厚度） × (1 − R_r（参考环电阻）/R_s（传感环电阻）)
                = d₀（初始厚度） × (1 − 1/(1 + V_diff（差分电压）/V_mid（中点电压）))

        若 V_mid（中点电压） = 0 → 标记为 "V_mid_zero" 错误，跳过计算
```

**数学证明（ρ(T) 消去）**：见 2.5.1 节推导。

**优化策略**：
- 比值夹持 [0.5, 2.0] 防止异常值污染下游算法
- 零电压检测保护除零错误

---

### 4.3 Level 2: 比值法自校准

**目的**：检测恒流源 I 的短期漂移，评估比值法消去 I 的有效性。

**输入**：10 个连续读数窗口的 V_ref (=V_mid) 序列

**算法步骤**：

```
Step 1: 计算滑动窗口内 V_ref（参考电压） 的相对标准偏差
        fluctuation（波动率） = σ(V_ref)（标准差） / mean(V_ref)（均值）

Step 2: 判定
        若 fluctuation > 0.1% → 恒流源短期不稳定
        若连续检测到不稳定 → 触发 Level 2 告警 "恒流源异常"
```

**设计理由**：比值法理论上可消去 I 漂移，但前提是 V_mid 和 V_diff 的**测量时刻对齐**。若 I 在两次测量间剧烈波动，消去效果将被破坏。

---

### 4.4 Level 3A: 残余温度系数多项式修正

**目的**：即使硬件差分已消除 ρ(T) 的一阶效应，传感环和参考环之间仍可能存在**残余温度耦合**（如 Parylene C 涂层应力、焊点热电势等），需用多项式进一步修正。

**输入**：Δd_raw、T（当前温度）、T₀（参考温度 = 25°C）、α_res、β_res

**算法**：

```
Δd_corrected（修正腐蚀深度） = Δd_raw（原始腐蚀深度） / (1 + α_res（一次残余系数）·(T（温度） − T₀（参考温度）) + β_res（二次残余系数）·(T（温度） − T₀（参考温度）)²)
```

**参数设置**：

| 参数 | 默认值 | 含义 |
|:---|:---|:---|
| α_res | **0** | 一次温度系数 (Ω/K) |
| β_res | **0** | 二次温度系数 (Ω/K²) |
| T₀ | 25.0°C | 参考温度 |

**跳过条件**：当 α_res = 0 且 β_res = 0 时，校正退化为恒等映射 Δd_corrected = Δd_raw，**自动跳过**。

**优化策略**：α_res 和 β_res 可通过实验室恒温箱标定获取。出厂默认为 0（即信任硬件差分已充分消去温度效应），用户可通过系统设置界面导入标定值。

### 4.5 Level 3B: 湿度门控滤波器

**目的**：在干燥条件下（RH < 76% NaCl 潮解临界值），判断 ER 探针信号是否来自真实腐蚀还是干燥盐沉积伪影。

**算法原理**：

```
ε_noise（噪声阈值） = ε_multiplier（噪声乘数） × σ_n（噪声标准差）   (噪声阈值，默认 3σ)

┌────────────────────────────────────────────────────────────────────────────────────┐
│ 若 RH（相对湿度） ≥ 76%:                                                             │
│   → 满足腐蚀电化学条件                                                                │
│   → ValidFlag（有效标志） = 1（始终通过）                                              │
│                                                                                    │
│ 若 RH（相对湿度） < 76% 且 |Δd_raw（原始腐蚀深度）| ≥ ε_noise（噪声阈值）:                │
│   → 干燥但信号超出噪声                                                                │
│   → ValidFlag（有效标志） = 0（可疑：可能为干燥盐沉积）                                  │
│                                                                                    │
│ 若 RH（相对湿度） < 76% 且 |Δd_raw（原始腐蚀深度）| < ε_noise（噪声阈值）:                │
│   → 干燥且信号在噪声范围内                                                             │
│   → ValidFlag（有效标志） = 1（通过：无显著信号）                                       │
├────────────────────────────────────────────────────────────────────────────────────┤
│ 连续 10 次 ValidFlag（有效标志） = 0                                                  │
│   → 触发 "探针/电路异常" 告警                                                          │
└────────────────────────────────────────────────────────────────────────────────────┘
```

**噪声阈值标定**（24 小时初始化阶段）：

```
step 1: 收集初始 24 小时的 Δd_raw（原始腐蚀深度） 序列
step 2: 用 IQR 方法排除离群点 (Q1−1.5·IQR ~ Q3+1.5·IQR)
step 3: 计算清洗后数据的标准差 σ_n（噪声标准差）
step 4: 设置 ε_noise（噪声阈值） = ε_multiplier（噪声乘数） × σ_n（噪声标准差）（默认 multiplier = 3）
```

**参数**：

| 参数 | 默认值 | 说明 |
|:---|:---|:---|
| RH_crit | **76.0%** | NaCl 潮解临界相对湿度 |
| ε_multiplier | **3.0** | 噪声标准差乘数 |
| 连续无效阈值 | **10 次** | 触发异常告警的连续无效次数 |

### 4.6 Level 3C: 环境因子归一化修正

**目的**：将实测腐蚀速率从实际环境条件"归一化"到标准参考条件，实现**不同时期、不同风机的横向可比性**。

**输入**：CR_raw（当前腐蚀速率）、TOW_actual（实际年化湿润小时）、TOW_ref（参考湿润小时 = 4000 h/yr）、S_Cl⁻（氯离子沉积率）、k_S（盐度敏感系数 = 0.01）

**算法**：

```
CR_norm（归一化腐蚀速率） = CR_raw（原始腐蚀速率） × (TOW_ref（参考湿润时间） / TOW_actual（实际湿润时间）) × 1/(1 + k_S（盐度敏感系数） × S_Cl⁻（氯离子沉积率）)
```

**各项物理意义**：

| 修正因子 | 公式 | 物理含义 |
|:---|:---|:---|
| TOW 归一化 | TOW_ref / TOW_actual | 湿润时间越多 → 腐蚀越快 → 归一化时向下修正 |
| 盐度归一化 | 1/(1 + k_S·S_Cl⁻) | 盐度越高 → 腐蚀越快 → 归一化时向下修正 |

**保护措施**：TOW 因子夹持在 [0.1, 10.0] 范围内，防止极端条件导致数值溢出。

### 4.7 Level 3D: 剂量-响应函数预测与交叉验证

**目的**：基于环境参数（T, RH, Cl⁻）**独立预估**腐蚀速率，与实测值交叉比对，识别异常加速或涂层保护效应。

**剂量-响应函数**（海上环境，SO₂ 忽略）：

```
r_pred（预测腐蚀速率） = 0.102 × [Cl⁻]（氯离子浓度）^0.62 × exp(0.033·RH（相对湿度） + 0.040·T（温度）)  [μm/year]
```

**各因子物理含义**：

| 因子 | 指数 | 物理含义 |
|:---|:---|:---|
| [Cl⁻]^0.62 | 0.62 | 氯离子对腐蚀速率的亚线性促进作用 |
| exp(0.033·RH) | 0.033 | 湿度每增加 10%，腐蚀速率约增加 39% |
| exp(0.040·T) | 0.040 | 温度每增加 10°C，腐蚀速率约增加 49% |

**交叉验证三区间判定**：

```
ratio（交叉比） = r_meas（实测腐蚀速率） / r_pred（预测腐蚀速率）

┌──────────────────────────────────────────┐
│ 0.5 ≤ ratio ≤ 2.0                        │
│ → NORMAL（实测与预测一致）                 │
│ → 无告警                                  │
├──────────────────────────────────────────┤
│ ratio > 2.0                               │
│ → ABNORMAL_ACCELERATION（异常加速）        │
│ → ratio > 4.0: Level 2 告警               │
│ → 2.0 < ratio ≤ 4.0: Level 1 告警         │
│ → 可能原因：涂层破损、微生物腐蚀、缝隙腐蚀   │
├──────────────────────────────────────────┤
│ ratio < 0.5                               │
│ → COATING_EFFECTIVE（涂层有效保护）         │
│ → 无告警，记录为涂层保护状态               │
│ → 可能原因：防腐涂层完好、缓蚀剂作用         │
└──────────────────────────────────────────┘
```

**与 ISO 9223 的关系**：若实测 ISO 等级比环境估算等级高 ≥ 2 级，触发"腐蚀加速异常"告警。

### 4.8 Level 4: 自适应卡尔曼滤波器

#### 4.8.1 状态空间建模

**状态向量**（2 维）：

```
x（状态向量） = [Δd（腐蚀深度）, CR（腐蚀速率）]ᵀ

Δd: 腐蚀深度 (μm)
CR: 腐蚀速率 (μm/year)
```

**状态转移方程**（常速模型）：

```
        ┌          ┐
x_k（k时刻状态）  =  │ 1    dt（时间步长）  │ · x_{k-1}（k-1时刻状态）  +  w_{k-1}（过程噪声）
        │ 0    1   │
        └          ┘

dt（时间步长） = Δt_seconds（采样间隔秒） / (8760 × 3600)   [年]
```

**测量方程**（直接测量 Δd）：

```
z_k（k时刻测量值） = [1, 0] · x_k（k时刻状态）  +  v_k（测量噪声）
```

#### 4.8.2 自适应过程噪声协方差

传统卡尔曼滤波使用固定的过程噪声协方差 Q，无法适应环境剧烈变化场景。本系统采用**自适应 Q 策略**：

```
env_scale（环境缩放因子） = 1 + |dT/dt（温度变化率）|/10 + |dRH/dt（湿度变化率）|/50
env_scale（环境缩放因子） ∈ [1, 100]   (夹持保护)

G（噪声增益矩阵） = ┌ dt³/3   dt²/2 ┐
                    └ dt²/2    dt    ┘

Q（过程噪声协方差） = G（噪声增益矩阵） × q_rate（基础过程噪声） × env_scale（环境缩放因子）
```

**物理含义**：当温度或湿度急剧变化时（|dT/dt| 大、|dRH/dt| 大），增大 Q 值，使滤波器更"信任"测量值而非模型预测，快速跟踪真实状态。

#### 4.8.3 Joseph 形式协方差更新

标准卡尔曼滤波的协方差更新式 `P = (I−KH)P` 在数值上可能失去对称性和正定性。本系统采用**Joseph 形式**保证数值稳定性：

```
K（卡尔曼增益） = P（协方差矩阵）·Hᵀ·(H·P（协方差矩阵）·Hᵀ + R（测量噪声协方差）)⁻¹
x（状态向量） = x（状态向量） + K（卡尔曼增益）·(z（测量值） − H·x（状态向量）)
P（协方差矩阵） = (I − K（卡尔曼增益）·H)·P（协方差矩阵）·(I − K（卡尔曼增益）·H)ᵀ + K（卡尔曼增益）·R（测量噪声协方差）·Kᵀ   ← Joseph 形式
P（协方差矩阵） = (P + Pᵀ)/2                           ← 对称性强制
```

#### 4.8.4 暖启动策略

- **最少预热样本**：36 个（6 小时 × 10 分钟采样）
- 初始状态协方差：`P₀（初始协方差） = [[1×10⁶, 0], [0, 1×10⁴]]`（高初始不确定性）
- 前 36 个样本仅执行预测 + 更新，不输出滤波结果
- 第 37 个样本起开始输出 `Δd_filtered` 和 `CR_filtered`

#### 4.8.5 参数配置

| 参数 | 默认值 | 说明 |
|:---|:---|:---|
| measurement_noise_var | 基于 24h σ_n² | 测量噪声方差 R |
| base_process_noise (q_rate) | 可配置 | 基础过程噪声 |
| MIN_WARMUP_SAMPLES | **36** | 最少预热样本数 |
| dt (采样间隔) | Δt / (8760×3600) | 年化时间步长 |

### 4.9 双模冗余交叉验证

#### 4.9.1 核心决策逻辑

双模交叉验证是系统的"最终仲裁层"，通过比较 ER 探针和电感探针的独立测量结果，判定腐蚀数据的可信度及腐蚀模式。

```
输入: Δd_ER, Δd_Inductive, dT/dt (温度变化率)

Step 1: 计算相对偏差
        diff（相对偏差） = |CR_ER（ER腐蚀速率） − CR_Inductive（电感腐蚀速率）| / [(CR_ER（ER腐蚀速率） + CR_Inductive（电感腐蚀速率）) / 2]

Step 2: 三场景判定
```

**场景 1 — 双模一致** (diff < 0.15)：

```
→ 两种独立物理原理的测量结果吻合
→ 高置信度：数据可信
→ CR_out（输出腐蚀速率） = 0.6 × CR_ER（ER腐蚀速率） + 0.4 × CR_Inductive（电感腐蚀速率）   (ER 权重更高)
→ alarm_level = 0（无告警）
→ 判定: DUAL_CONSISTENT
```

**场景 2 — 温度冲击** (diff ≥ 0.15 且 |dT/dt| > 2°C/10min)：

```
→ 环境温度急剧变化导致 ER 和电感响应不同步
→ ER 探针受温度冲击影响更大（ρ(T) 的残余效应）
→ CR_out（输出腐蚀速率） = 0.2 × CR_ER（ER腐蚀速率） + 0.8 × CR_Inductive（电感腐蚀速率）   (电感高权重)
→ alarm_level = 1 (Level 1 信息通知)
→ 判定: TEMPERATURE_SHOCK
```

**场景 3 — 可能点蚀** (diff ≥ 0.15 且 |dT/dt| ≤ 2°C/10min)：

```
→ 排除温度冲击后，ER 和电感的显著偏差 → 可能为局部点蚀
→ δ（点蚀偏差比） = |Δd_ER（ER腐蚀深度） − Δd_Inductive（电感腐蚀深度）| / Δd_ER（ER腐蚀深度）  (点蚀偏差比率)
→ η（点蚀因子） = f(δ)  从标定曲线插值获得点蚀因子
→ Δd_actual（实际最大深度） = η（点蚀因子） × Δd_ER（ER腐蚀深度）  (最大点蚀深度估计)

→ η > 5.0: alarm_level = 4 (紧急：穿孔风险)
→ η > 3.0: alarm_level = 3 (高级：点蚀风险)
→ η ≤ 3.0: alarm_level = 0 (偏差不足以判定)
→ 判定: PITTING_SUSPECTED
```

**关键阈值汇总**：

| 阈值 | 值 | 含义 |
|:---|:---|:---|
| DIFF_THRESHOLD | **0.15 (15%)** | ER/电感相对偏差触发阈值 |
| DT_DT_THRESHOLD | **2.0°C/10min** | 温度冲击判定阈值 |
| ETA_THRESHOLD_PITTING | **3.0** | 点蚀判定 η 阈值 |
| ETA_THRESHOLD_SEVERE | **5.0** | 严重点蚀/穿孔 η 阈值 |

#### 4.9.2 点蚀因子标定曲线

点蚀因子 η 不是直接测量的量，而是通过实验室标定和经验模型建立 η = f(δ) 映射关系：

### 4.10 ISO 9223/9224 腐蚀性评估

#### 4.10.1 TOW (Time of Wetness) 年湿润时间统计

**ISO 9223 TOW 定义**：每小时若同时满足 `T > 0°C` 且 `RH > 80%`，则该小时计为 1 个湿润小时。

```
TOW_annual（年湿润时间） = TOW_accumulated（累计湿润小时） × (8760 / total_hours（总采样小时）)
```

**TOW 分级**：

| 等级 | 年湿润时间范围 | 描述 |
|:---|:---|:---|
| τ1 | 0 < TOW ≤ 10 h | 极短 (Very Short) |
| τ2 | 10 < TOW ≤ 250 h | 短 (Short) |
| τ3 | 250 < TOW ≤ 2500 h | 中等 (Medium) |
| τ4 | 2500 < TOW ≤ 5500 h | 长 (Long) |
| τ5 | > 5500 h | 极长 (Very Long) |

#### 4.10.2 腐蚀性等级判定 (ISO 9223)

基于碳钢第一年腐蚀速率：

| 等级 | 腐蚀速率范围 (μm/year) | 描述 |
|:---|:---|:---|
| C1 | 0 < r ≤ 1.3 | 很低 (Very Low) |
| C2 | 1.3 < r ≤ 25 | 低 (Low) |
| C3 | 25 < r ≤ 50 | 中 (Medium) |
| C4 | 50 < r ≤ 80 | 高 (High) |
| C5 | 80 < r ≤ 200 | 很高 (Very High) |
| CX | > 200 | 极端 (Extreme) |

#### 4.10.3 ISO 9224 长期腐蚀预测

```
D(t)（t年累计腐蚀深度） = r_corr_year1（第一年腐蚀速率） × t（年数）^b（幂指数）

其中: b（幂指数） = 0.523 (碳钢幂指数)
      预测时间点: t（年数） ∈ {1, 5, 10, 25} 年
```

**预测逻辑**：基于第一年实测/估算腐蚀速率，按幂函数规律推算 5/10/25 年累计腐蚀深度。幂指数 b = 0.523 < 1 反映了腐蚀速率随时间递减的物理规律（腐蚀产物层的保护效应）。

#### 4.10.4 实测 vs 环境估算交叉比对

通过 TOW-盐度联合查表可得到基于环境参数的独立腐蚀性估算。将实测等级与估算等级对比：

```
若 |实测等级 − 估算等级| ≥ 2 → 触发 "腐蚀加速异常" 告警
```

## 5. 补偿机制的设计与实现

### 5.1 补偿体系总览

本系统的补偿机制是一个**分级递进、逐级消去误差源**的结构化体系。每一级针对特定的误差源，采用相应的物理或数学方法进行消除：

```
┌────────────────────────────────────────────────────────────────────┐
│                       补偿层级          误差源         方法          │
├────────────────────────────────────────────────────────────────────┤
│  L1: 硬件差分补偿    ρ(T) 温度依赖性    双环结构比值消去    硬件级  │
│  L2: 比值法自校准    I 恒流源漂移       V_diff/V_mid 消去    电路级  │
│  L3A: 残余温度修正   残余热耦合效应      多项式校正          数学级  │
│  L3B: 湿度门控       干燥盐沉积伪影      RH 临界值判定       逻辑级  │
│  L3C: 环境归一化     环境条件差异        TOW + Cl⁻ 因子修正  统计级  │
│  L3D: 剂量-响应交叉   隐蔽腐蚀异常        r_meas/r_pred 比对  模型级  │
│  L4: 卡尔曼滤波      随机噪声 + 瞬态扰动  自适应状态估计      滤波级  │
└────────────────────────────────────────────────────────────────────┘
```

### 5.2 L1 + L2: 硬件级与电路级补偿

**补偿模型**：通过物理结构设计（叠加双环）和电路拓扑（串联恒流 + 差分放大），在信号采集源头即消除两个最核心的误差源。

**L1 补偿方程**：

```
Δd_raw（原始腐蚀深度） = d₀（初始厚度） × (1 − R_r（参考环电阻）/R_s（传感环电阻）) = d₀（初始厚度） × (1 − 1/(1 + V_diff（差分电压）/V_mid（中点电压）))
```

其中 ρ(T) 在 `R_s/R_r` 比值运算中被完全消去。这是**本系统最重要的技术创新**——用物理设计替代软件补偿，从根源上抑制误差。

**L2 补充机制**：在 V_ref 10 个读数滑动窗口内监测波动率，波动率 > 0.1% 时标记恒流源不稳定。

**应用场景**：适用于所有正常腐蚀监测场景，是系统的默认工作基线。

---

### 5.3 L3A: 残余温度系数校准

**补偿模型**：

```
Δd_corrected（修正腐蚀深度） = Δd_raw（原始腐蚀深度） / (1 + α_res（一次残余系数）·(T（温度） − T₀（参考温度）) + β_res（二次残余系数）·(T（温度） − T₀（参考温度）)²)
```

**校准方法**：
1. 将 ER 探针置于恒温箱中
2. 在 −10°C ~ 60°C 范围内选取 5~8 个温度点
3. 每温度点稳定 30 分钟后，记录 Δd_raw 和 T
4. 以 (T − T₀) 为自变量，Δd_raw/Δd_corrected 为因变量，进行二次多项式拟合
5. 提取 α_res 和 β_res 系数
6. 通过系统设置界面导入至配置文件

**应用场景**：
- **默认出厂**：α_res = 0, β_res = 0（信任硬件差分补偿）→ 自动跳过
- **高精度需求**：实验室标定后导入非零系数，进一步降低温度误差
- **极端温度环境**：如极寒海域（−20°C~0°C）或热带海域（30°C~50°C），温差大时残余效应更显著

---

### 5.4 L3B: 湿度门控——干燥条件下数据可信度判定

**补偿模型**：

```
ValidFlag（有效标志） = 1, 若 RH（相对湿度） ≥ RH_crit（临界湿度） (76%)
ValidFlag（有效标志） = 1, 若 RH（相对湿度） < RH_crit（临界湿度） 且 |Δd_raw（原始腐蚀深度）| < ε_noise（噪声阈值）
ValidFlag（有效标志） = 0, 若 RH（相对湿度） < RH_crit（临界湿度） 且 |Δd_raw（原始腐蚀深度）| ≥ ε_noise（噪声阈值）
```

**应用场景**：
- **高湿环境**（RH ≥ 76%）：NaCl 已潮解，腐蚀正在进行，所有信号有效
- **干湿交替**（RH 在 76% 附近波动）：有效识别"湿→干"过渡期间的数据有效性
- **长期干燥**（RH ≪ 76%）：排除干燥盐颗粒在探头表面的物理沉积干扰

**ε_noise（噪声阈值） 动态校准**：基于 24 小时初始运行数据，利用 IQR 排除离群点后计算 3σ（3倍标准差），确保噪声阈值适应具体安装环境。

---

### 5.5 L3C: 环境因子归一化

**补偿模型**：

```
CR_norm（归一化腐蚀速率） = CR_raw（原始腐蚀速率） × (TOW_ref（参考湿润时间） / TOW_actual（实际湿润时间）) × 1/(1 + k_S（盐度敏感系数） × S_Cl⁻（氯离子沉积率）)
```

**应用场景**：
- **多风机对比**：同一风场不同机位，因朝向、通风条件不同导致微环境差异，归一化后实现公平对比
- **季节性对比**：不同季节湿润时间和盐雾沉降量不同，归一化后消除季节性偏差
- **趋势分析**：长期趋势分析需排除环境条件波动的干扰，聚焦于材料/涂层状态的真实变化

---

### 5.6 L4: 自适应卡尔曼滤波——动态噪声抑制

**补偿模型**：

```
状态: x（状态向量） = [Δd（腐蚀深度）, CR（腐蚀速率）]ᵀ
预测: x̂_k|k-1（先验估计） = F（状态转移矩阵）·x̂_{k-1}（后验估计）
更新: x̂_k（后验估计） = x̂_k|k-1（先验估计） + K_k（卡尔曼增益）·(z_k（测量值） − H（测量矩阵）·x̂_k|k-1（先验估计）)

自适应 Q（过程噪声协方差）: Q = Q_base（基础过程噪声） × (1 + |dT/dt（温度变化率）|/10 + |dRH/dt（湿度变化率）|/50)
Joseph 更新: P（协方差矩阵） = (I−KH)·P（协方差矩阵）·(I−KH)ᵀ + K（卡尔曼增益）·R（测量噪声协方差）·Kᵀ
```

**应用场景**：

| 环境条件 | Q 行为 | 滤波器表现 |
|:---|:---|:---|
| 稳定环境 (dT/dt ≈ 0, dRH/dt ≈ 0) | Q ≈ Q_base（小） | 强平滑，有效滤除随机测量噪声 |
| 缓慢变化 (dT/dt ≈ 1°C/10min) | Q ≈ 1.1 × Q_base | 适度跟踪 |
| 剧烈变化 (dT/dt ≈ 10°C/10min) | Q ≈ 2.0 × Q_base | 快速响应，避免滤波滞后 |
| 极端变化 (dT/dt > 50°C/10min) | Q → 100 × Q_base (夹持) | 几乎等价于直接使用测量值 |

**优化策略**：
- Joseph 形式保证协方差矩阵 P 的对称正定性，避免数值发散
- `P = (P + Pᵀ)/2` 强制对称，作为额外数值保护
- Q 夹持 [Q_base, 100×Q_base] 防止极端条件下滤波发散

## 6. 误差分析

### 6.1 误差来源识别

系统的整体测量误差来源于多个独立环节，采用**误差传播定律**进行综合量化：

```
总不确定度 = √(u_T²（温度不确定度） + u_H²（湿度不确定度） + u_Cl²（氯离子不确定度） + u_ER²（ER探针不确定度） + u_Ind²（电感探针不确定度） + u_cal²（标定不确定度） + u_env²（环境归一化不确定度） + u_algo²（算法不确定度）)

其中:
  u_T: 温度测量不确定度
  u_H: 湿度测量不确定度
  u_Cl: 氯离子沉积率不确定度
  u_ER: ER 探针测量不确定度
  u_Ind: 电感探针测量不确定度
  u_cal: 标定不确定度
  u_env: 环境因子归一化不确定度
  u_algo: 算法近似不确定度
```

### 6.2 各误差源的量化评估

#### 6.2.1 传感器级误差

| 误差源 | 标称精度 | 对腐蚀深度的影响 | 控制措施 |
|:---|:---|:---|:---|
| Pt1000 温度 | ±0.15°C | 经 L1 硬件差分消去 ρ(T) → 影响极小 | Class A 铂电阻 + L1 差分结构 |
| SHT35 湿度 | ±1.5% RH | 影响 L3B 门控判定 ±1.5% 范围内的边界情况 | 选用高端数字传感器 + CRC-8 校验 |
| QCM 盐沉积 | ~1 ng | 影响 Cl⁻ 沉积率转换为腐蚀速率的精度 | Sauerbrey 方程灵敏度分析 + 定期基频校准 |
| ER Probe 电压 | ADC 16-bit @ 3.3V | 量化误差 ≈ 0.05 mV，Δd 折算 ≈ 0.003 μm | 16-bit ADC + 电压差分放大 |
| LDC1614 电感 | 28-bit 分辨率 | 亚纳米级位移/厚度检测 | 28-bit 高精度 + 耦合健康检查 |

#### 6.2.2 ER 探针的系统误差

**残余温度效应**（在 L3A 修正之前）：
- 硬件差分理论上完全消去 ρ(T)，但传感环/参考环之间的热梯度、涂层热膨胀差异等残余效应实测 < **0.5% per 10°C**
- 通过 L3A 多项式修正可进一步降低至 < **0.1% per 10°C**

**恒流源漂移**：
- 标称稳定度 < 0.1%
- 通过 L2 比值法在 V_diff/V_mid 运算中消去 I
- 短期波动超标触发告警，提示人工核实

**参考环退化**：
- Parylene C 涂层长期老化或机械损伤 → 参考环也可能发生微量腐蚀
- 30 天周期诊断检测 V_ref 漂移 > ±1% 时告警

#### 6.2.3 算法级不确定度

| 误差源 | 不确定度量级 | 来源 |
|:---|:---|:---|
| 卡尔曼滤波平滑偏差 | < 1 μm (稳态) | 当真实速率阶跃变化时，滤波器存在过渡过程滞后 |
| 标定曲线插值误差 | < 5% η (线性插值) | 默认 10 点线性插值；可切换为 3 阶多项式拟合降低 |
| ISO 9224 幂律模型 | ±20% (预测 25 年) | 幂函数模型内在的统计不确定性 |
| 剂量-响应函数 | ±30% (单次预测) | 经验公式的统计离散度 |

### A. 核心公式索引

| 编号 | 公式名称 | 表达式 | 所在章节 |
|:---|:---|:---|:---|
| (1) | CVD 正温方程 | R(T)（电阻-温度函数） = R₀（零度电阻）(1 + α（一次系数）T（温度） + β（二次系数）T²) | 2.2 |
| (2) | CVD 逆解 | T（温度） = [−α（一次系数） + √(α²−4β（二次系数）(1−R（电阻）/R₀（零度电阻）))] / (2β) | 2.2 |
| (3) | Sauerbrey 方程 | Δf（频率偏移） = −(2f₀²)/(A（面积）√(ρ_q（石英密度）·μ_q（剪切模量）)) × Δm（质量变化） | 2.4 |
| (4) | Cl⁻ 沉积率 | Cl（沉积率） = (Δm（质量变化）/(A（面积）·Δt（时间间隔）)) × 8.64×10¹⁰ | 2.4 |
| (5) | 双环差分比值 | R_s（传感环电阻）/R_r（参考环电阻） = d₀（初始厚度）/(d₀（初始厚度）−Δd（腐蚀深度）) | 2.5 |
| (6) | 腐蚀深度工作公式 | Δd（腐蚀深度） = d₀（初始厚度）(1 − R_r（参考环电阻）/R_s（传感环电阻）) | 2.5 |
| (7) | 电压比值消 I | Δd（腐蚀深度） = d₀（初始厚度）[1 − 1/(1+V_diff（差分电压）/V_mid（中点电压）)] | 2.5 |
| (8) | L3A 温度修正 | Δd_corr（修正腐蚀深度） = Δd_raw（原始腐蚀深度） / (1+α_res（一次残余系数）·ΔT（温差）+β_res（二次残余系数）·ΔT²) | 4.4 |
| (9) | L3C 环境归一化 | CR_norm（归一化速率） = CR_raw（原始速率） × (TOW_ref（参考湿时）/TOW_act（实际湿时）) / (1+k_S（盐度系数）·S_Cl（氯沉积）) | 4.6 |
| (10) | 剂量-响应 | r_pred（预测速率） = 0.102·[Cl⁻]（氯浓度）^0.62·exp(0.033·RH（湿度）+0.040·T（温度）) | 4.7 |
| (11) | 卡尔曼状态转移 | F（转移矩阵） = [[1,dt（时间步长）],[0,1]]，自适应 Q（过程噪声） | 4.8 |
| (12) | 双模偏差比 | δ（点蚀偏差比） = \|Δd_ER（ER腐蚀深度）−Δd_Ind（电感腐蚀深度）\| / Δd_ER（ER腐蚀深度） | 4.9 |
| (13) | ISO 9224 预测 | D(t)（累计深度） = r₁（首年速率） × t（年数）^0.523 | 4.10 |
